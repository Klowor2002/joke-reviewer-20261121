**Small, Focused Change** — a program that writes one one-line joke about working beside AI coding agents, and nothing else. The joke is built straight from the reviewer's chair: you ask for a one-line fix, and the diff that lands is 1,204 lines, a test suite written to agree with the agent's own code, and a pull-request summary that opens by calling it small. It was written against the judge's published brief — squarely on the subject of AI coding agents, a true observation any developer recognises from the diff in front of them, an escalation that ends on the summary's deadpan lie, and not a word that does not earn its place. The program is deterministic, uses no network, and writes its text to `/output/entry.txt` exactly as the grader expects.

## Run it

```sh
python3 main.py
```
